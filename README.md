# 데일리 증시 리포트

매일 갱신하는 증시 요약 리포트. GitHub Pages로 배포됩니다.

## 공유 링크 (친구에게 이 주소만 보내세요)

> https://songpacity.github.io/daily-stock-report/

- 메인 페이지는 **항상 가장 최근 날짜 리포트**를 자동으로 보여줍니다.
- 상단 **날짜 드롭다운**에서 다른 날짜를 고르면 그날 리포트가 나옵니다.
- 특정 날짜 바로 공유: `.../daily-stock-report/#2026-10-16` 처럼 `#날짜`를 붙이면 됩니다.

## 구조

```
index.html           ← 메인(껍데기). 드롭다운 + 최신 리포트 표시. 건드릴 일 없음.
DailyReport/         ← 여기에 날짜별 리포트를 넣기만 하면 자동 등록됨
  2026-10-16.html
  2026-10-17.html
  ...
```

메인 페이지가 GitHub 공개 API로 `DailyReport/` 폴더를 읽어 드롭다운을 자동 구성합니다.
**별도 목록 파일을 관리할 필요가 없습니다.**

## 매일 업데이트 방법 (딱 이것만)

1. Claude로 증시 리포트 HTML을 뽑는다.
2. 파일을 `DailyReport/` 안에 **`YYYY-MM-DD.html`** 이름으로 넣는다.
   - 예: `DailyReport/2026-10-17.html`
   - (`증시리포트_2026-10-17.html` 처럼 접두어가 붙어도 날짜만 들어있으면 인식됩니다.)
3. 커밋 & 푸시:

   ```bash
   cd ~/daily-stock-report
   git add -A
   git commit -m "report: YYYY-MM-DD"
   git push
   ```

4. 약 1분 뒤 메인 페이지 드롭다운에 자동으로 나타나고, 최신 날짜면 기본 화면이 그걸로 바뀝니다.

## 주의
- 파일명에 **`YYYY-MM-DD`** 형식 날짜가 반드시 들어가야 목록에 뜹니다.
- 공개(public) 저장소라 링크를 아는 사람은 누구나 볼 수 있습니다.
